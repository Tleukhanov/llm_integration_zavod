# Фоновая музыка (Background Music)

## Что это

Опциональная функция: под финальный ролик накладывается фоновая музыка
(например, phonk-трек), а оригинальный комментарий приглушается (ducking).

## Настройки

| Переменная              | Значение по умолчанию | Описание |
|-------------------------|-----------------------|----------|
| `SHORTS_BGM_MODE`       | `off`                 | Режим работы: `off`, `music`, `mix50`, `auto` |
| `SHORTS_MUSIC_DIR`      | `D:\shorts_music`     | Папка с аудиофайлами (.mp3, .m4a, .ogg, .wav) |
| `SHORTS_BGM_VOLUME`     | `0.30`                | Громкость фоновой музыки (0.0–1.0) |

### Режимы

- **off** — фоновая музыка отключена (по умолчанию).
- **music** — фоновая музыка добавляется во все клипы.
- **mix50** — примерно половина клипов получает музыку, половина остаётся
  чистой (детерминированно для заданного seed).
- **auto** — включает музыку во все клипы. В будущем планируется привязка
  к «энергичным» окнам внимания.

## Куда складывать треки

Положите аудиофайл с расширением `.mp3`, `.m4a`, `.ogg` или `.wav` в
папку, указанную в `SHORTS_MUSIC_DIR` (по умолчанию `D:\shorts_music`).

Скачать треки можно скриптом:

```bash
python scripts/fetch_music.py --dir D:/shorts_music <url1> <url2>
```

## Авторское право (Copyright)

**Важно!** Использование музыки без надлежащей лицензии может привести
к DMCA-страйкам на канале. Рекомендуемые источники **royalty-free**
музыки:

- [Pixabay Music](https://pixabay.com/music/) — бесплатная музыка,
  не требуется указание автора.
- [Free Music Archive](https://freemusicarchive.org/) — лицензии
  Creative Commons.
- [YouTube Audio Library](https://studio.youtube.com/channel/UC/music)
  — бесплатные треки для контента на YouTube.

Не скачивайте phonk и другую музыку напрямую у артистов без разрешения
— это почти гарантированно приведёт к претензиям правообладателей
(DMCA / Content ID) и потере канала.

## Как это работает

1. Для каждого клипа в пайплайне определяется, нужна ли фоновая музыка
   (`should_use_bgm`).
2. Если нужна — выбирается случайный трек из папки (`pick_track`).
3. В ffmpeg-фильтре:
   - оригинал (video + commentary) идёт через `volume=1.0` (с дакингом
     через `amix`).
   - фоновая музыка проходит через `volume=<bgm_volume>`.
   - оба потока смешиваются в один (`amix=inputs=2:duration=first`).
4. Длительность итогового видео всегда равна длительности оригинала
   (`duration=first`).

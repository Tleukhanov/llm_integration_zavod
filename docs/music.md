# Фоновая музыка (Background Music)

## Что это

Опциональная функция: под финальный ролик накладывается фоновая музыка
(например, phonk-трек), а оригинальный комментарий приглушается (ducking).

## Настройки

| Переменная              | Значение по умолчанию | Описание |
|-------------------------|-----------------------|----------|
| `SHORTS_BGM_MODE`       | `off`                 | Режим работы: `off`, `music`, `mix50`, `auto` |
| `SHORTS_MUSIC_DIR`      | `D:\shorts_music`     | Папка с аудиофайлами (.mp3, .m4a, .ogg, .wav) |
| `SHORTS_BGM_VOLUME`     | `0.30`                | Громкость фоновой музыки (0.0–1.0) |
| `SHORTS_SYNTHESIZE_MUSIC` | `true`              | Синтезировать луп, если в папке нет ни одного трека |

### Режимы

- **off** — фоновая музыка отключена (по умолчанию).
- **music** — фоновая музыка добавляется во все клипы.
- **mix50** — примерно половина клипов получает музыку, половина остаётся
  чистой (детерминированно для заданного seed).
- **auto** — включает музыку во все клипы. В будущем планируется привязка
  к «энергичным» окнам внимания.

## Куда складывать треки

Положите аудиофайл с расширением `.mp3`, `.m4a`, `.ogg` или `.wav` в
папку, указанную в `SHORTS_MUSIC_DIR` (по умолчанию `D:\shorts_music`).

Скачать треки можно скриптом:

```bash
python scripts/fetch_music.py --dir D:/shorts_music <url1> <url2>
```

## Авторское право (Copyright)

**Важно!** Использование музыки без надлежащей лицензии может привести
к DMCA-страйкам на канале. Рекомендуемые источники **royalty-free**
музыки:

- [Pixabay Music](https://pixabay.com/music/) — бесплатная музыка,
  не требуется указание автора.
- [Free Music Archive](https://freemusicarchive.org/) — лицензии
  Creative Commons.
- [YouTube Audio Library](https://studio.youtube.com/channel/UC/music)
  — бесплатные треки для контента на YouTube.

Не скачивайте phonk и другую музыку напрямую у артистов без разрешения
— это почти гарантированно приведёт к претензиям правообладателей
(DMCA / Content ID) и потере канала.

### Процедурно-сгенерированный phonk (не нужно лицензировать)

В `docs` репозитория нет бинарных аудиофайлов (они бы раздули git и
затруднили лицензирование). Вместо этого используется генератор:

```bash
python scripts/make_phonk.py   # -> D:/shorts_music/generated_phonk_loop.wav
```

Скрипт синтезирует **оригинальный** phonk-луп (~90 c, 132 BPM) только
средствами стандартной библиотеки (`wave`, `math`, `struct`) и numpy:
808-кик, паттерн коровьих колокольчиков на E/A (классический phonk),
скользящий 808-бас с насыщением (tanh), хай-хэты в стиле trap, 4/4.
Так как это полностью оригинальная синтезированная композиция, лицензия
не требуется.

### Автоматический фолбэк (чтобы клип не вышел тихим)

Скрапер (`ensure_phonk_tracks`) требует сети или ключей Jamendo/Pixabay, а на
свежем клоне `SHORTS_MUSIC_DIR` пуст — раньше такой запуск заканчивался роликом
без музыки. Поэтому после попытки скачивания пайплайн вызывает
`ensure_synthesized_track` (`shorts_clipper/captions/music.py`): если в папке
по-прежнему нет ни одного пригодного трека, рендерится оригинальный
dark-industrial луп (~90 c, 134 BPM, peak 0.92, фиксированный seed) и
складывается как `dark_industrial_loop.wav`.

- Скачанные треки всегда важнее: синтез срабатывает только на пустой папке и
  ничего не перезаписывает.
- Идемпотентно: перед рендером папка проверяется повторно, повторные запуски
  ничего не перерисовывают.
- Ошибка синтеза логируется как warning, рендер продолжается без музыки.
- Имя файла намеренно **не** начинается с `generated_`: такие файлы
  `pick_track` отфильтровывает (см. `SHORTS_ALLOW_PROCEDURAL_MUSIC`).

Отключить: `SHORTS_SYNTHESIZE_MUSIC=0`.

Весь DSP живёт в `shorts_clipper/audio/dark_industrial.py`; скрипт — тонкая
CLI-обёртка:

```bash
python scripts/make_dark_industrial.py                        # -> data/music/dark_industrial_loop.wav
python scripts/make_dark_industrial.py --duration 20 --out x.wav
```

## Выбор трека

`pick_track` теперь предпочитает треки, достаточно длинные
(`>= 60 c`), чтобы покрыть клип за один проход без зацикливания
(`amix duration=first` обрывает музыку на конце трека). Длительность
читается для WAV нативно (без ffmpeg), для остальных форматов — через
ffprobe/ffmpeg с кэшированием на процесс. Если длинных/поддающихся
замеру треков нет, выбор остаётся полностью случайным.

## Как это работает

1. Для каждого клипа в пайплайне определяется, нужна ли фоновая музыка
   (`should_use_bgm`).
2. Если нужна — выбирается случайный трек из папки (`pick_track`).
3. В ffmpeg-фильтре:
   - оригинал (video + commentary) идёт через `volume=1.0` (с дакингом
     через `amix`).
   - фоновая музыка проходит через `volume=<bgm_volume>`.
   - оба потока смешиваются в один (`amix=inputs=2:duration=first`).
4. Длительность итогового видео всегда равна длительности оригинала
   (`duration=first`).

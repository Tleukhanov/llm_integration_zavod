# Affiliate-партнёры

Модуль `shorts_clipper/affiliate/partners.py` загружает партнёров из JSON-файла и
добавляет их оффер (ссылка + тег `#ad`) в описание клипа, а при
`affiliate_enabled = true` — накладывает `banner_path` как логотип в углу видео.

## Где лежит файл

- По умолчанию — `affiliate_partners.json` в корне проекта (путь задаёт
  `affiliate_partners_path` в настройках).
- Переопределить можно через env-переменную `AFFILIATE_PARTNERS_PATH`.

Готовый пример — в файле `affiliate_partners.example.json`. Чтобы начать работу:

1. Скопируйте пример: `affiliate_partners.example.json` → `affiliate_partners.json`.
2. Заполните реальных партнёров (см. ниже).

## Формат файла

Top-level должен быть **списком** объектов. Каждый партнёр поддерживает поля:

| Поле              | Обязательное | Описание                                                               |
| ----------------- | ------------ | ---------------------------------------------------------------------- |
| `id`              | да           | Уникальный идентификатор партнёра.                                     |
| `name`            | да           | Название, которое попадает в описание клипа.                           |
| `link_en`         | да           | Ссылка для англоязычной аудитории.                                     |
| `link_ru`         | нет          | Ссылка для русскоязычной аудитории (берётся, если язык начинается с `ru`). |
| `banner_path`     | нет          | Путь к файлу логотипа/баннера (накладывается на видео).                |
| `tag`             | нет          | Тег-дисклеймер, по умолчанию `#ad`.                                     |
| `match_keywords`  | нет          | Список ключевых слов; партнёр выбирается, если все они есть в транскрипте. |
| `enabled`         | нет          | `true`/`false`. Отключённые партнёры игнорируются, по умолчанию `true`.  |

## RU vs EN ссылки

Если указан `link_ru` и язык ролика начинается с `ru`, используется `link_ru`,
иначе — `link_en`. Это удобно для партнёрок с разными лендингами/рефами.

## Баннер

Поле `banner_path` указывает на файл изображения. Если `affiliate_enabled = true`
и файл существует, баннер масштабируется до ширины 200px и накладывается в угол
(по умолчанию `bottom_left`, менять через `affiliate_banner_position`).

## Как заполнить реальных партнёров

- Замените заглушки `https://example.com/<partner>/<streamer_id>` на ваши
  реферальные ссылки (например, для CS:GO/CS2-маркетплейсов скинов).
- В `match_keywords` перечислите слова по-русски и по-английски, по которым
  должна срабатывать привязка («кейс», «skin», «cs2» и т.п.).
- Отключённого партнёра можно временно убрать из ротации, поставив
  `"enabled": false`, не удаляя запись.
